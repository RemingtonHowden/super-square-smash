# Super Square Smash website

Static site: marketing page, support page, and privacy policy. No build step.

## Publish on GitHub Pages

1. Create a public GitHub repository named `super-square-smash`.
2. Copy the contents of this `Website` folder to the repository root and push.
3. In the repository Settings, open Pages, choose "Deploy from a branch", branch `main`, folder `/ (root)`.
4. Replace `RemingtonHowden` in `support.html` with your GitHub username.

The site is then live at `https://RemingtonHowden.github.io/super-square-smash/`.
